Overview

Compai is a companion chatbot that lets users chat with a virtual version of someone they wish to speak to, reproducing that person's speaking style in any scenario. It is designed as a safe and controlled emotional outlet. Users upload an exported Telegram chat history; Compai learns the speaker's style from it and answers through a Telegram bot, using retrieval-augmented generation (RAG) over past conversations with the Gemini API and ChromaDB.

Key Features

Short-term Memory

Keeps the last five messages in a double-ended queue so replies stay on topic.

Long-term Memory

Extracts details such as age, preferences, and dislikes from history into key-value records for more relevant responses.

Speaker Style Adaptation

Analyzes writing style, tone, and emoji usage so responses sound like the designated speaker.

Telegram Integration

Accepts an uploaded chat history and automatically recognizes both users' IDs, then chats in real time.

How It Works

  1. Ingest. The exported Telegram JSON is loaded in chunks with orjson, embedded, and stored in a ChromaDB collection.
  2. Learn the style. The speaker's communication style is analyzed from the conversation history.
  3. Retrieve. For each query, RAG searches ChromaDB for similar past conversations and combines them with the stored key-value facts and the last five messages.
  4. Generate. Gemini (gemini-1.5-flash) produces a reply from this combined context and the speaker's style, so it feels natural and personalized.

My Role

System Architecture

Designed the overall pipeline: how chat history is ingested, how short- and long-term memory and RAG retrieval are combined, and how responses are generated.

Lead Developer

Wrote most of the codebase, implementing the memory, retrieval, and generation modules.

Performance Optimization

Embedding acceleration: conversation data is embedded in batches instead of message by message, which reduces the number of API calls.

Results

Compai adapts accurately to the designated speaker's style. The style can also be changed easily through the prompt for any desired tone, for example a "warm & sweet" chat environment.
