# Fan-Yi Hsu

Personal website: <https://flyih.github.io>

Built with [Jekyll](https://jekyllrb.com/) and the [al-folio](https://github.com/alshedivat/al-folio) starter, and deployed to GitHub Pages by GitHub Actions on every push to `main`.

## Local preview

```bash
bundle install
bundle exec jekyll serve --config _config.yml,_config.local.yml
```

Then open <http://localhost:4000/>.
